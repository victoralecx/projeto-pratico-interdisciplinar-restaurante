## Projeto

Página de menu para o restaurante fictício **Sabores da Floresta**, desenvolvida com HTML e CSS.

## Requisitos atendidos

- Página principal `menu.html`;
- Cabeçalho com nome e logotipo fictício;
- Menu de navegação;
- Três categorias de pratos:
  - Entradas;
  - Pratos principais;
  - Sobremesas;
- Dois pratos em cada categoria, totalizando 6 pratos;
- Nome, descrição e preço de cada prato;
- Imagens ilustrativas dos pratos;
- Estilização completa em CSS;
- Layout responsivo;
- Rodapé com informações de contato fictícias.

## Arquivos

- `menu.html` — estrutura HTML da página;
- `style.css` — estilos visuais;
- `imagens/` — logotipo e ilustrações dos pratos.

## Como abrir

Abra o arquivo `menu.html` em qualquer navegador moderno.
